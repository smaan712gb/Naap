# Garment measurement protocol — the "BOSS 40R method"

How a garment on a table becomes a verified fit-library row. Ten minutes
per garment, one tape measure, a hard flat surface. This is the protocol
for the founder's own closet today and for paid tailor-contributors
later (outreach ladder: per verified entry).

## Rules

- Measure the GARMENT, never a person. Lay it flat, buttoned/zipped,
  smoothed but not stretched.
- Record in centimetres to the nearest 0.5.
- Photograph the brand/size label and the care label (fiber content) —
  that photo is the row's evidence.
- Note the line (BOSS main vs Orange, Emporio vs Giorgio) — houses cut
  differently per line; a row without the line is half a row.

## Jacket / blazer (flat)

| Field | How |
| --- | --- |
| chest_flat | pit seam to pit seam, straight across (×2 = around) |
| waist_flat | narrowest point between pits and hem |
| shoulder | shoulder seam to shoulder seam across the back |
| sleeve | shoulder seam to cuff end, along the outside |
| back_length | base of collar seam to hem, center back |
| bicep_flat | 2.5 cm below pit seam, across the sleeve |

## Trousers (flat)

| Field | How |
| --- | --- |
| waist_flat | across the closed waistband (×2 = around) |
| hip_flat | 18 cm below waistband top, across |
| thigh_flat | at the crotch seam, across one leg |
| knee_flat | midpoint of inseam, across |
| leg_opening | across the hem |
| inseam | crotch seam to hem, inside leg |
| front_rise | crotch seam to waistband top, front |

## Shirt (flat)

chest_flat (pit-to-pit), shoulder, sleeve (shoulder seam→cuff),
collar (buttonhole center → button center), length (collar seam→hem).

## Kurta / kameez (flat)

chest_flat (pit-to-pit), shoulder, sleeve, length from HSP (highest
shoulder point → hem), collar if banned. Same fields the Pakistani
brands' own charts use — rows compare directly.

## Submitting a row

Send: brand, line, garment, size label, the numbers, and the label
photos. It becomes a `GarmentEntry` with
`evidence: "measured on table YYYY-MM-DD by <initials>, label photo"`,
and `verified: true` only after a second person (or the founder)
eyeballs numbers against the photo. Wearer's fit verdict (true-to-size /
snug / roomy) is welcome as a note — it triangulates the chart data.
